# 工具描述盲评问卷

下面有 8 组中文工具描述，每组有 A、B 两个版本，描述的是同一个工具。

想象你正在给一个 AI agent 配置工具列表，agent 只能看到这段文字、看不到代码。对每一组回答：

1. **哪个版本更适合直接放进工具列表？** 选 A、B，或「差不多」。
2. **一句话说明原因。**
3. （可选）你觉得哪个版本里有让 agent 容易用错的地方？

不要猜哪个是改写的，按你自己的判断选。

```
参数 userIds（必填）：接收者的 userId 列表。调用方用英文逗号分隔各个 userId。列表最多包含 100 个 userId。
参数 context（必填）：消息内容。消息内容不超过 2048 个字节。
```

## 第 6 组

**版本 A**

```
工具名：maps_direction_walking_by_coordinates
描述：步行路径规划 API 可以根据输入起点终点经纬度坐标规划100km 以内的步行通勤方案，并且返回通勤方案的数据
```

```
参数 origin：起点的经纬度坐标。格式为"经度,纬度"，经度在前。例如："116.434307,39.90909"。
参数 destination：终点的经纬度坐标。格式为"经度,纬度"，经度在前。例如："116.434307,39.90909"。
```

## 第 7 组

**版本 A**

```
工具名：baidu_search
描述：工具使用百度搜索互联网信息。工具返回搜索结果列表。每条搜索结果包含标题、摘要和链接。

⚠️ 重要使用规则：
1. 每个用户问题只调用一次 baidu_search。不得用不同关键词重复搜索同一主题。
2. 如果搜索结果不够详细，使用 fetch_url 工具深入查看，而不是重新搜索。
3. baidu_search 的搜索耗时较长。请谨慎使用 baidu_search。

适用场景：
- 实时信息
- 新闻事件
- 最新数据
- 用户明确要求搜索的内容

baidu_search 特别适合搜索中文内容。
参数 query：搜索查询词。query 支持中文和英文。
```

**版本 B**

```
工具名：baidu_search
描述：使用百度搜索互联网信息。返回搜索结果列表，包含标题、摘要和链接。

⚠️ 重要使用规则：
1. 每个用户问题只调用一次，不要用不同关键词重复搜索相同主题
2. 如果结果不够详细，使用 fetch_url 工具深入查看，而不是重新搜索
3. 搜索耗时较长，请谨慎使用

适用场景：实时信息、新闻事件、最新数据、用户明确要求搜索的内容。特别适合中文内容搜索。
参数 query：搜索查询词，支持中英文
```
