缓存数据脏了、需要清除时，按以下步骤操作：

1. 不得直接执行 `FLUSHALL`。`FLUSHALL` 会同时清掉 session，所有人都要重新登录。
2. 用 `redis-cli --scan --pattern 'product:*'` 找出 key。
3. 分批 `UNLINK` 这些 key，每批约 500 个。
4. 清完后，观察数据库 CPU。如果数据库 CPU 超过 70%，先停止清除，等 CPU 降下来再继续。
