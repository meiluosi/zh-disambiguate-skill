工具在只读副本上执行 SQL 查询，然后返回结果行。
工具只接受 `SELECT` 语句。其他语句会直接报错。
工具不接受 `EXPLAIN ANALYZE`，因为 `EXPLAIN ANALYZE` 会真实运行查询。
运行超过 30 秒的查询会被终止。查询被终止时，工具返回错误码 `QUERY_TIMEOUT`，不返回部分结果。
收到 `QUERY_TIMEOUT` 后，调用方必须缩小查询范围再重试。调用方不得原样重发同一个查询。
行数超过约 500 万的表是大表。目前的大表主要是 `events` 和 `order_items`。
查询 `events` 或 `order_items` 时，调用方必须同时满足以下两个条件：
1. 查询带上 `created_at` 的范围条件。
2. `LIMIT` 不超过 1000。
不满足这两个条件时，查询基本跑不完。
查询小表时，调用方可以不带这两个条件。
