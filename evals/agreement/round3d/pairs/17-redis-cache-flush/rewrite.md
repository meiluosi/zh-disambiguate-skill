缓存数据脏了、需要清理时，按以下步骤处理：

1. 不得执行 `FLUSHALL`。`FLUSHALL` 会把 session 一起清掉，所有用户都必须重新登录。
2. 执行 `redis-cli --scan --pattern 'product:*'`，找出要清理的 key。`product:*` 只是例子。你必须把 pattern 改成实际受影响的前缀。pattern 不得匹配到 session 前缀 `sess:*`。
3. 分批执行 `UNLINK`，清理这些 key。每批 500 个左右。批与批之间执行 `sleep 1`。
4. 清完后，在主库监控面板上观察数据库 CPU。缓存清理后，请求会穿透到数据库。
5. 如果数据库 CPU 持续 1 分钟超过 70%，先暂停 `UNLINK`。等数据库 CPU 回到 50% 以下后，再继续。

保留未改：（1）「清完后」是指每批清完后观察数据库 CPU，还是全部 key 清完后观察？（2）「回到 50% 以下」是否包含 50%？
